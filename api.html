For developers

Use Framewrite via API

Everything Framewrite does in the browser is also a simple REST API — submit a job, poll for status, and pull down the finished document. Same pay-as-you-go pricing, no extra cost to integrate.

1

Get an API key

Generate one from Settings → API Keys after signing in. Keys are shown once, so save it somewhere safe. Send it with every request as an X-API-Key header.

2

Submit a video or audio file

Upload starts the job and returns immediately — conversion happens in the background.

curl -X POST https://api.framewrite.cc/api/convert_to_doc \
  -H "X-API-Key: YOUR_KEY" \
  -F "video=@meeting.mp4"

# {"job_id": "5f2b6b3e-...", "status": "queued"}

Have audio instead of video? POST to /api/transcribe_audio with -F "audio=@call.mp3" instead — priced at $0.40/hour rather than $1/hour.

3

Check status and get your document

curl "https://api.framewrite.cc/api/get_status?job_id=5f2b6b3e-..." \
  -H "X-API-Key: YOUR_KEY"

# {"status": "done", "document_url": ".../document.md",
#  "document_bundle_url": ".../bundle.zip", ...}

Once status is done, download the result from document_url (Markdown) or document_bundle_url (a zip with the document and its images). Word and PDF exports are included whenever available.
